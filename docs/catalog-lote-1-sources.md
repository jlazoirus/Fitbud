# Catalogo lote 1 - fuentes nutricionales

REQ-135 amplio el catalogo local con ingredientes comunes para desayunos,
snacks, batidos y cenas ligeras. Los valores son aproximaciones por 100 g para
planificacion, no etiquetado legal. Cuando un producto depende de marca
(`skyr`, proteinas en polvo, wraps, jamon de pavo), el valor se tomo como
promedio de etiquetas comerciales; para alimentos genericos se uso una tabla
publica tipo USDA/FoodData Central como referencia de revision humana.
